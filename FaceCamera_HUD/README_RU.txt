ГОТОВЫЙ ПРОЕКТ FaceCamera HUD 1.1

Что уже работает:
- собственная задняя камера телефона;
- обнаружение лиц через Google ML Kit;
- рамки вокруг найденных лиц;
- часы;
- процент заряда батареи;
- HUD-интерфейс;
- кнопки Камера 1-4;
- Камера 1 использует этот телефон;
- Камеры 2-4 пока являются кнопками-заглушками;
- карта пока является областью-заглушкой;
- распознавания текста нет;
- приложение не сохраняет фотографии и видео.

Установка:
1. Распакуйте ZIP.
2. Откройте папку FaceCamera_HUD в Android Studio: File -> Open.
3. Дождитесь Gradle Sync.
4. Если Android Studio попросит Android SDK 35, установите его через SDK Manager.
5. Подключите телефон с USB-отладкой.
6. Нажмите Run.
7. Разрешите доступ к камере.

Чтобы получить APK:
Build -> Build Bundle(s) / APK(s) -> Build APK(s).
После сборки Android Studio покажет ссылку на APK.
